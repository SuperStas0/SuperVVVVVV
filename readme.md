# SuperVVVVVV
Patch for VVVVVV game, that has following features

## Savestates
Allows you to create a save state at any point, saving position, room, checkpoint, and other player info

Works only in `Time Trials` and `Intermissions`

- Shift + ~ to save state
- ~ to load state

# Quick Start
## Install
1. Download patched executable from releases page and move it to a new folder
2. Download a `SDL2.dll` from `SDL2/bin/` and move next to executable
3. Get `data.zip` from your original VVVVVV installation folder and move next to executable
